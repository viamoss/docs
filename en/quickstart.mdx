# Quick Start

Add the Moss assistant to a React app in three steps. For other sites, use the [CDN script tag](/en/sdk/installation#cdn-script-tag).

<Info>
    You need your **Application ID**, shown in the [Moss Dashboard](https://dashboard.viamoss.ai) under **Configure > General**, and a JWT signing key. See [Authentication](/en/sdk/authentication).
</Info>

## 1. Install the SDK

```bash
npm install @viamoss/moss-sdk
```

The package is private: the npm account or token you install with needs access to it. If npm refuses the install, contact Moss.

The SDK needs React 18. See [Requirements](/en/sdk/installation#requirements).

## 2. Add Moss to Your App

Add `AgentProvider` and `AssistantButton`. The provider does not need to wrap your whole app, only the Moss components.

```tsx App.tsx
import { AgentProvider, AssistantButton } from '@viamoss/moss-sdk';

function App() {
  return (
    <>
      <YourApp />
      <AgentProvider config={{
        apiUrl: 'https://moss-api.viamoss.ai',
        applicationId: 'YOUR_APP_ID',
        userId: currentUser.id,
        getJwt: () => fetchMossToken(),
      }}>
        <AssistantButton />
      </AgentProvider>
    </>
  );
}
```

<Tip>
    `AgentProvider` reads the whole page wherever it sits in the React tree.
</Tip>

<Warning>
    In Next.js or another framework that renders on the server, load the SDK in the browser only, or the import throws. See [Server-side rendering](/en/sdk/installation#server-side-rendering).
</Warning>

## 3. Set Up Authentication

Create a backend endpoint that signs a token for the signed-in user. `fetchMossToken()` above calls it. See [Authentication](/en/sdk/authentication) for the full setup.

```typescript app/api/moss-token/route.ts
// Next.js App Router route handler, served at /api/moss-token
import jwt from 'jsonwebtoken';
import { getCurrentUser } from '@/lib/auth'; // your own session lookup

export async function GET(request: Request) {
  const user = await getCurrentUser(request);
  if (!user) {
    return new Response('Unauthorized', { status: 401 });
  }

  const token = jwt.sign(
    {
      sub: String(user.id),                // Required: your user's ID, as a string
      app: 'YOUR_APP_ID',                  // Required: the Moss application ID
    },
    process.env.MOSS_JWT_SECRET!,          // The moss_sk_… secret
    {
      algorithm: 'HS256',
      expiresIn: '1h',                     // Sets exp; jsonwebtoken adds iat
      keyid: process.env.MOSS_KEY_ID!,     // The key_… ID, sent as the kid header
    }
  );

  return Response.json({ token });
}
```

```typescript
async function fetchMossToken(): Promise<string> {
  const response = await fetch('/api/moss-token');
  if (!response.ok) throw new Error('Could not get a Moss token');
  return (await response.json()).token;
}
```

## What's Next?

Moss now shows a floating button at the bottom right of your app. Clicking it opens the chat.

Before you go live, decide what Moss may read from your pages. The values of native form fields (`input`, `textarea`, `select`) are redacted by default, but not in vision screenshots. Mark other sensitive areas, including custom controls built from other elements, with `data-moss-redact`.
