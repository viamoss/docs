## 세션이란

세션은 하나의 채팅입니다. 사용자와 Moss가 주고받은 메시지와 그 안에서 실행된 가이드가 세션에 속합니다. Moss는 현재 세션을 브라우저에 기억하므로, 사용자가 페이지를 이동하거나 새로 고쳐도 같은 채팅으로 돌아옵니다.

세션은 사용자가 새 채팅을 시작하거나, 아래 두 가지 제한 중 하나를 넘으면 끝납니다.

## 두 가지 제한

| 옵션 | 단위 | 기본값 | 기준 시점 |
|------|------|--------|-----------|
| `sessionConfig.inactivityTimeout` | 분 | `30` | 사용자가 채팅에서 마지막으로 활동한 때 |
| `sessionConfig.maxSessionAge` | 시간 | `2` | 채팅이 시작된 때 |

```tsx
<AgentProvider config={{
  apiUrl: 'https://moss-api.viamoss.ai',
  applicationId: 'YOUR_APP_ID',
  userId: currentUser.id,
  getJwt: () => fetchMossToken(),
  sessionConfig: {
    inactivityTimeout: 15, // 분
    maxSessionAge: 1,      // 시간
  },
}}>
  <AssistantButton />
</AgentProvider>
```

- **활동**은 메시지를 보내거나 가이드 단계를 진행하는 것입니다. 페이지가 열려 있는 동안에는 채팅을 열고 닫는 것도 활동으로 칩니다.
- **값을 지정하지 않거나 `0`으로 두면** 기본값이 적용됩니다. 제한을 사실상 없애려면 큰 값을 지정하세요.
- **제한은 사용자가 돌아왔을 때 확인합니다.** 백그라운드 타이머로 확인하지 않습니다. Moss가 페이지에 로드될 때 확인하고, 아래의 `'new_chat'`을 쓰면 열려 있던 페이지에서 사용자가 채팅을 다시 열 때도 확인합니다. 화면에 열려 있는 채팅이 사용 중에 닫히는 일은 없습니다.

## 제한을 넘었을 때의 동작

`sessionConfig.onReturnAfterInactivity`가 결정합니다.

| 값 | 비활성 시간 초과 후 | 최대 유지 시간 초과 후 |
|----|---------------------|------------------------|
| `'ask'` (기본값) | **이 대화 이어가기**와 **새 대화** 중에서 고르는 카드가 나타나며, 한 번의 탭으로 평가할 수 있습니다. 카드를 닫으면 채팅이 이어집니다. | 새 채팅이 시작됩니다. 카드가 이를 알리고 평가를 선택 사항으로 제안합니다. |
| `'new_chat'` | 카드와 평가 없이 새 채팅이 시작됩니다. | 동일합니다. |

```tsx
sessionConfig: {
  inactivityTimeout: 15,
  maxSessionAge: 1,
  onReturnAfterInactivity: 'new_chat',
}
```

다음 경우에는 다르게 동작합니다.

- **내용이 거의 없는 채팅**(메시지 2개 미만)은 두 모드 모두에서 조용히 새로 시작합니다.
- **진행 중인 가이드**는 최대 유지 시간만으로는 끝나지 않습니다. 비활성 시간을 넘으면 `'ask'`는 카드를 보여 주고, `'new_chat'`은 채팅과 함께 가이드를 끝냅니다.
- **사용자를 다른 페이지로 이동시키는 가이드 단계**는 이동 중에 제한을 넘어도 채팅을 유지합니다.

### 알림

Moss가 카드 없이 스스로 새 채팅을 시작하면 "비활성 상태로 인해 새로운 대화를 시작했습니다."와 같은 짧은 알림을 보여 줍니다. 알림을 끄려면 `showNotification: false`로 설정하세요.

```tsx
sessionConfig: {
  onReturnAfterInactivity: 'new_chat',
  showNotification: false,
}
```

## 각 설정을 읽어 오는 위치

Moss를 설치한 방식에 따라 다릅니다.

| 설치 방식 | `inactivityTimeout`, `maxSessionAge`, `showNotification` | `onReturnAfterInactivity` |
|-----------|-----------------------------------------------------------|---------------------------|
| npm 패키지 (`AgentProvider`) | 앱 코드의 설정을 따릅니다. 대시보드 값은 적용되지 않습니다. | 앱 코드에 설정하면 그 값, 없으면 대시보드 설정, 그것도 없으면 `'ask'`입니다. |
| CDN 스크립트 | 대시보드 값을 따릅니다. | 대시보드 값을 따릅니다. |

대시보드 필드는 **구성 > 동작 > 세션 동작**에 있습니다: **시간 초과 (분)**, **최대 유지 시간 (시간)**, **비활성 후 사용자가 돌아오면**, **알림**.

CDN 스크립트에서는 `window.mossSettings`의 `sessionConfig` 객체가 대시보드의 시간 초과, 최대 유지 시간, 알림 설정을 통째로 대체합니다. 빠뜨린 필드는 대시보드 값이 아니라 기본값으로 돌아갑니다. 셋 중 하나를 거기에 설정한다면 세 필드를 모두 설정하세요. `onReturnAfterInactivity`만 예외로, 빠뜨리면 대시보드 설정을 그대로 따릅니다.

<Warning>
    npm 패키지를 쓰는 경우 대시보드에서 **시간 초과 (분)** 값이나 **최대 유지 시간 (시간)** 값을 바꿔도 효과가 없습니다. 앱 코드에서 `sessionConfig.inactivityTimeout`과 `sessionConfig.maxSessionAge`를 설정하세요.
</Warning>

<Info>
    대시보드의 "비활성 후 사용자가 돌아오면" 설정은 백엔드 0.16.22와 SDK 0.16.22부터 npm 임베드에 전달됩니다.
</Info>

## 새 채팅 시작하기

사용자는 채팅 헤더에 있는 새 채팅 시작 버튼으로 언제든지 새 채팅을 시작할 수 있습니다. 앱에서도 같은 동작을 호출할 수 있습니다.

```tsx
const { startNewChat } = useAgent();

await startNewChat();
```

`useAgent()`의 나머지 기능은 [Hooks](/ko/sdk/api/hooks)를 참고하세요.

## 이전 대화

0.17.0부터 사용자는 시작 화면에서 자신의 이전 대화를 다시 열 수 있습니다. 대시보드에서 켜기 전까지는 꺼져 있습니다: **구성 > 동작 > 세션 동작 > 사용자가 이전 대화를 다시 열 수 있도록 허용**.

- 시작 화면의 **최근 대화** 아래에 사용자의 최근 대화 3개가 나타나고, 나머지는 **모두 보기**로 볼 수 있습니다.
- 로그인한 사용자 본인의 최근 30일 대화만 나타나며, 보존 기간을 넘은 대화는 나타나지 않습니다.
- 이전 대화는 읽기 전용으로 열립니다. 입력한 질문은 현재 채팅에서 처리되고, Moss는 이전 대화를 답변에 사용하지 않습니다.

<Warning>
    사용자마다 본인 계정으로 로그인하는 경우에만 켜세요. 여러 사람이 같은 `userId`를 쓰면 서로의 대화가 보입니다.
</Warning>

## 세션 유지 시간은 데이터 보존 기간이 아닙니다

이 페이지의 제한은 사용자가 채팅에서 보는 내용을 결정할 뿐, 아무것도 삭제하지 않습니다.

- **대화를 얼마나 오래 저장할지**는 대시보드의 **구성 > 데이터 및 개인정보**에서 애플리케이션별로 설정합니다(0.17.0부터). [데이터 및 개인정보](/ko/dashboard/data-privacy)를 참고하세요.
- **사용자 토큰의 유효 기간**은 서버에서 서명하는 JWT가 결정합니다. [인증](/ko/sdk/authentication)을 참고하세요.
- **대시보드에서 세션이 종료됨으로 표시되는 시점**은 서버가 결정합니다. 기본적으로 세션의 마지막 메시지로부터 30분 뒤입니다. 이후에 메시지가 오면 다시 열립니다. [세션](/ko/dashboard/sessions)을 참고하세요.

Moss는 현재 채팅의 내용만으로 답변합니다. 새 채팅은 이전 채팅에서 나눈 내용을 이어받지 않습니다.

## 세션 녹화

대시보드에서 다시 보기 위한 세션 녹화는 별도의 설정이며, 켜기 전까지는 꺼져 있습니다. [페이지 데이터와 개인정보 제어](/ko/sdk/page-data)를 참고하세요.

## 자주 묻는 질문

**대시보드에서 시간 초과를 바꿨는데 아무 변화가 없습니다.**
앱이 npm 패키지를 사용하고 있습니다. npm 패키지는 두 제한을 앱 코드에서 읽습니다. [각 설정을 읽어 오는 위치](#각-설정을-읽어-오는-위치)를 참고하세요.

**사용자가 입력하는 도중에 채팅이 끝날 수 있나요?**
아니요. 제한은 사용자가 채팅으로 돌아왔을 때 확인하며, 채팅이 열려 있는 동안에는 확인하지 않습니다.

**시간이 지난 채팅을 사용자가 되찾을 수 있나요?**
`'ask'`에서는 비활성 시간 초과 후 카드가 **이 대화 이어가기**를 제안합니다. 최대 유지 시간을 넘었거나 `'new_chat'`을 쓰면 채팅이 새것으로 바뀝니다. 0.17.0부터는 [이전 대화](#이전-대화)로 사용자가 지난 대화를 읽을 수 있습니다.
