# TypeScript 타입

npm 패키지에는 TypeScript 선언이 들어 있습니다. 타입은 패키지 루트에서 import하세요.

```tsx
import type {
  MossSDKConfig,
  AgentState,
  ChatMessage,
  DefaultModalPosition,
  StabilityConfig,
} from '@viamoss/moss-sdk';
import { LogLevel } from '@viamoss/moss-sdk'; // enum이므로 값으로 import합니다
```

아래 타입은 0.17.0 기준입니다. 에디터에서도 패키지의 선언에 담긴 같은 설명을 볼 수 있습니다.

---

## 핵심 타입

### AgentState

`useAgent()`가 반환하는 값입니다. 각 멤버의 동작은 [Hooks](/ko/sdk/api/hooks)를 참고하세요.

```typescript
interface AgentState {
  // 연결과 채팅
  isConnected: boolean;
  isChatOpen: boolean;
  messages: ChatMessage[];
  sendMessage: (text: string, attachments?: AttachmentRef[]) => Promise<void>; // attachments: 0.17.0부터
  openChat: (defaultPosition?: DefaultModalPosition) => void;
  closeChat: () => void;
  toggleChat: (defaultPosition?: DefaultModalPosition) => void;
  startNewChat: () => Promise<void>;
  activeChatSessionId: string | null;

  // 진행 상태
  isWaitingForResponse: boolean;
  isRetrievalExpected: boolean;

  // 적용 중인 설정
  useVision: boolean;
  debugMode: boolean;

  // 가이드
  chatMode: 'chat' | 'guide';
  suggestsGuideMode: boolean;
  planPhase: 'offered' | 'executing' | null | undefined;
  continueGuide: () => Promise<void>;
  acceptGuideSuggestion: () => Promise<void>;
}
```

<Note>
    선언된 `AgentState`에는 Moss 자체의 디버그 도구와 개발 중인 기능을 위한 멤버가 몇 가지 더 있습니다. 여기서는 다루지 않으며, 예고 없이 바뀔 수 있습니다. 0.17.0부터 `displayMode`는 없어졌습니다.
</Note>

### ChatMessage

채팅의 메시지 하나입니다.

```typescript
interface ChatMessage {
  id: string;
  sender: 'user' | 'assistant';
  text: string;
  timestamp: number;
  userFeedback?: 'helpful' | 'unhelpful';
  sources?: MessageSource[];
  isHallucinated?: boolean;
  attachments?: ChatMessageAttachment[]; // 0.17.0부터
  problem?: MessageProblem;              // 0.17.0부터
  activity?: MessageActivity;            // 0.17.0부터
}
```

| 필드 | 타입 | 의미 |
|-------|------|---------|
| `id` | `string` | 고유한 메시지 ID |
| `sender` | `'user' \| 'assistant'` | 보낸 쪽 |
| `text` | `string` | 텍스트. Markdown이 들어 있을 수 있습니다 |
| `timestamp` | `number` | 메시지가 추가된 시각. Unix epoch부터의 밀리초입니다 |
| `userFeedback` | `'helpful' \| 'unhelpful'` | 답변에 대한 사용자의 좋아요 또는 싫어요 |
| `sources` | `MessageSource[]` | 답변이 인용한 도움말 문서. 답변 아래에 표시됩니다 |
| `isHallucinated` | `boolean` | 답변이 가리킨 요소를 Moss가 페이지에서 찾지 못하면 `true` |
| `attachments` | `ChatMessageAttachment[]` | 사용자 메시지와 함께 보낸 파일. 각각 `{ filename: string }`입니다 |
| `problem` | `MessageProblem` | 턴에 문제가 있었던 답변에 설정됩니다 |
| `activity` | `MessageActivity` | 백엔드가 알려 준 경우(`streamActivity`), 답변을 만든 턴에서 Moss가 밟은 단계 |

```typescript
interface MessageSource {
  title: string;
  url?: string | null;
  source?: string | null;
  readTimeMinutes?: number | null;
  linkScope?: 'host' | 'prefix' | null;   // 0.17.0부터
  linkPrefix?: string | null;             // 0.17.0부터
}
```

0.17.0부터 다음 타입이 메시지의 문제와 그 뒤의 단계를 나타냅니다.

```typescript
interface MessageProblem {
  failed: boolean;                     // 턴이 답변하지 못했고, 텍스트가 실패 내용입니다
  notes: string[];                     // 무엇이 잘못되었는지, 한 줄에 하나씩
  fixBy: 'user' | 'admin' | 'moss';    // 해결할 수 있는 쪽
  action?: 'retry' | 'continue';       // 이 메시지가 마지막인 동안 제안하는 다음 동작
  reference?: string;                  // 지원팀에 알려 줄 값
}

interface MessageActivity {
  steps: MessageActivityStep[];
}

interface MessageActivityStep {
  id: string;
  kind: string;                        // 'retrieval', 도구 이름, 또는 'tool'
  state: 'ok' | 'error';
  result?: { count?: number; titles?: string[]; status?: string };
}

interface ChatMessageAttachment {
  filename: string;
}
```

### DefaultModalPosition

`openChat()`과 `toggleChat()`이 받는 위치와 크기입니다.

```typescript
interface DefaultModalPosition {
  x: number;       // 뷰포트 왼쪽 가장자리로부터의 거리(CSS 픽셀)
  y: number;       // 뷰포트 위쪽 가장자리로부터의 거리(CSS 픽셀)
  width: number;
  height: number;
}
```

## 설정 타입

### MossSDKConfig

`AgentProvider`의 `config` prop이자, CDN 스크립트에서 쓰는 `window.mossSettings`의 형태입니다. 각 옵션의 동작은 [설정](/ko/sdk/configuration)을 참고하세요.

```typescript
// 일부 생략: Moss 자체 도구용으로 예약된 옵션은 뺐습니다.
type MossSDKConfig = {
  // 필수
  apiUrl: string;
  userId: string;

  // 인증
  jwt?: string;
  getJwt?: () => Promise<string>;
  getBridgeCode?: () => Promise<string>;               // 0.17.0부터

  // 페이지 데이터와 개인정보
  pageContext?: 'full' | 'metadata' | 'none';
  redactAllInputs?: boolean;
  redactionSelectors?: string[];
  useVision?: boolean;
  screenshotMode?: ScreenshotMode;
  enableSessionRecording?: boolean;
  enableScreenHistoryRecording?: boolean;
  observeTargetSelector?: string;
  userMetadata?: Record<string, string | number | boolean | string[]>;
  collectionEnabled?: boolean;                         // 0.17.0부터
  collectionControl?: MossCollectionControl;           // 0.17.0부터
  pageSanitizationScript?: (document: Document) => void;

  // 동작
  language?: 'en' | 'ko';
  sessionConfig?: {
    inactivityTimeout?: number;                        // 분
    maxSessionAge?: number;                            // 시간
    showNotification?: boolean;
    onReturnAfterInactivity?: 'new_chat' | 'ask';
  };
  stability?: StabilityConfig;
  closingChatEndsGuide?: boolean;
  enableProactiveGuides?: boolean;
  streamActivity?: boolean;                            // 0.17.0부터
  replyLinks?: { allowedHosts?: string[] };            // 0.17.0부터

  // 외관
  appearance?: AppearanceInput;
  pageKey?: string;

  // 콜백
  onSupportTicket?: (handoff: SupportTicketHandoff) => Promise<SupportTicketOutcome>;
  onEvent?: (event: MossEvent) => void;
  eventQueryText?: 'omit' | 'include' | ((text: string) => string);
  onError?: (error: MossError) => void;                // 0.17.0부터

  // 진단
  logLevel?: LogLevel;
  debugMode?: boolean;
} & (
  | { applicationId: string; applicationName?: string }
  | { applicationName: string; applicationId?: string }
);
```

`applicationId`와 `applicationName` 중 하나는 꼭 있어야 하며, `applicationId`를 쓰세요. 0.17.0부터 `displayMode`, `headless`, `forcedActivationFlow`는 없어졌고 TypeScript가 이를 거부합니다. 내보내던 타입 `HeadlessConfig`, `ForcedActivationFlowConfig`, `ForcedActivationFlowDefinition`도 없어졌으므로, 이 타입을 import하는 코드는 더 이상 컴파일되지 않습니다.

`sessionConfig`에는 따로 내보내는 타입이 없습니다. `NonNullable<MossSDKConfig['sessionConfig']>`로 참조하세요. [세션](/ko/sdk/api/session)을 참고하세요.

### ScreenshotMode

```typescript
type ScreenshotMode = 'fullpage' | 'viewport';
```

0.17.0에서 채팅용 스크린샷에 아무 영향을 주지 않습니다. [페이지 데이터](/ko/sdk/page-data#비전-스크린샷)를 참고하세요.

---

### LogLevel

콘솔 로그의 양입니다. enum이므로 문자열 `'DEBUG'`가 아니라 `LogLevel.DEBUG`를 넘기세요.

```typescript
enum LogLevel {
  DEBUG = 1,
  INFO = 2,    // 기본값
  WARN = 3,
  ERROR = 4,
  SILENT = 5,  // 로그를 남기지 않음
}
```

```tsx
import { LogLevel } from '@viamoss/moss-sdk';

<AgentProvider config={{
  // ...
  logLevel: LogLevel.WARN,
}}>
```

## 안정성 타입

기본값과 동작은 [안정성 튜닝](/ko/sdk/advanced#안정성-튜닝)을 참고하세요.

### StabilityConfig

```typescript
interface StabilityConfig {
  afterReload?: {
    enabled?: boolean;                  // 기본값 false
    pendingTTL?: number;                // ms, 기본값 30000
  };
  maxTotalWaitMs?: number;              // 기본값 15000
  networkTimeoutMs?: number;            // 기본값 10000
  browserIdleTimeoutMs?: number;        // 기본값 500
  layers?: StabilityLayersConfig;
  loadingIndicators?: LoadingIndicatorsLayerConfig;
  layoutShift?: LayoutShiftLayerConfig;
  domMutations?: DOMMutationsLayerConfig;
  frameReadiness?: FrameReadinessLayerConfig;
  resourceQuiet?: ResourceQuietLayerConfig;
  placeholderGuard?: PlaceholderGuardConfig;
}
```

### StabilityLayersConfig

```typescript
interface StabilityLayersConfig {
  networkIdle?: boolean;        // 기본값 true
  domMutations?: boolean;       // 기본값 true
  loadingIndicators?: boolean;  // 기본값 false
  frameReadiness?: boolean;     // 기본값 true
  resourceQuiet?: boolean;      // 기본값 true
  layoutShift?: boolean;        // 기본값 false
  browserIdle?: boolean;        // 기본값 true
  finalFrame?: boolean;         // 기본값 true
}
```

### 레이어 설정

```typescript
interface DOMMutationsLayerConfig {
  enabled?: boolean;                 // false면 레이어를 끕니다
  quietPeriodMs?: number;            // 기본값 800
  excludeSelectors?: string[];
  countQuietBeforeLayer?: boolean;   // 기본값 true, 0.17.0부터
}

interface LoadingIndicatorsLayerConfig {
  enabled?: boolean;                 // false면 레이어를 끕니다
  selectors?: string[];              // 내장 목록을 대체합니다
  additionalSelectors?: string[];    // 내장 목록에 더합니다
  excludeSelectors?: string[];
  timeoutMs?: number;                // 기본값 5000
}

interface LayoutShiftLayerConfig {
  enabled?: boolean;                 // false면 레이어를 끕니다
  quietPeriodMs?: number;            // 기본값 200
  ignoreThreshold?: number;          // 기본값 0.01
}

interface FrameReadinessLayerConfig {
  enabled?: boolean;                 // false면 레이어를 끕니다
  quietMs?: number;                  // 기본값 200
  timeoutMs?: number;                // 기본값 10000
}

interface ResourceQuietLayerConfig {
  enabled?: boolean;                 // false면 레이어를 끕니다
  quietMs?: number;                  // 기본값 500
  timeoutMs?: number;                // 기본값 8000
}

interface PlaceholderGuardConfig {
  enabled?: boolean;                 // 기본값 true
  timeoutMs?: number;                // 기본값 4000. maxTotalWaitMs에 포함되지 않습니다
  selectors?: string[];
  additionalSelectors?: string[];
  excludeSelectors?: string[];
}
```

레이어 객체의 `enabled: true`로는 기본으로 꺼진 레이어가 켜지지 않습니다. 켤 때는 `layers`를 쓰세요.

## 외관 타입

각 부분이 무엇을 정하는지는 [외관](/ko/sdk/appearance)을 참고하세요.

```typescript
type AppearanceInput = 'blue' | 'purple' | DeepPartial<MossAppearance>;

type DeepPartial<T> = {
  [P in keyof T]?: T[P] extends object ? DeepPartial<T[P]> : T[P];
};
```

`MossAppearance`는 전체 테마입니다. 최상위 키는 `name`, `colors`, `typography`, `spacing`, `radius`, `shadows`, `effects`, `inputBar`, `progressBar`, `modal`, 그리고 선택 사항인 `layout`, `chrome`, `zeroState`, `fallbackStates`입니다. 바꾸고 싶은 값만 넘기세요.

```tsx
appearance: 'purple'                              // 프리셋

appearance: { colors: { primary: '#FF5722' } }    // 기본 프리셋 위에 덮어쓸 값
```

## 그 밖에 내보내는 타입

| 타입 또는 값 | 설명 | 문서 |
|---------------|------------|---------------|
| `MossEvent`, `MossEventName`, `MossEventCommonProperties`, `MossEventPropertiesByName`, `MOSS_EVENT_NAMES` | `onEvent`가 받는 사용 이벤트 | [이벤트](/ko/sdk/events) |
| `MossError`, `FeedbackReason` | 0.17.0부터. `onError`가 받는 문제, 싫어요를 누른 이유 | [이벤트](/ko/sdk/events) |
| `SupportTicketHandoff`, `SupportTicketPayload`, `SupportTicketOutcome` | `onSupportTicket`의 입력과 결과 | [지원 티켓 핸드오프](/ko/sdk/support-ticket-handoff) |
| `AskMossOptions`, `AskMossResult`, `FloatingActionBarProps` | `askMoss()`와 `FloatingActionBar` | [가이드와 페이지 이동](/ko/sdk/guides-and-navigation) |
| `ProactiveGuideConfig`, `ProactiveGuideRules`, `ProactiveGuideFrequency`, `ProactiveShoutOutContent`, `ProactiveUserMetadataPredicate`, `ProactiveCtaType` | 대시보드에서 설정한 프로액티브 가이드 | [가이드와 페이지 이동](/ko/sdk/guides-and-navigation) |
| `MossCollectionControl`, `CollectionIdentity` | 0.17.0부터. 수집 스위치 | [페이지 데이터](/ko/sdk/page-data#collectioncontrol) |
| `Persona` | 추천 콘텐츠 변형에 쓰는 `'admin' \| 'customer'` | [외관](/ko/sdk/appearance) |
| `AttachmentRef`, `MAX_ATTACHMENT_FILES`, `TooManyAttachmentsError` | 0.17.0부터. `sendMessage`의 첨부와 그 개수 제한(5개) | [Hooks](/ko/sdk/api/hooks) |
| `StabilityDiagnostics`, `StabilityLayerResult` | 한 번의 안정성 대기에서 잰 시간 | |
| `BackendSDKConfig`, `BackendConfigResponse` | `BackendSDKConfig`는 `fetchAppConfig()`가 반환하는 애플리케이션의 대시보드 설정이고, `BackendConfigResponse`는 그것을 감싼 HTTP 응답 `{ config, applicationId }`입니다 | [설정](/ko/sdk/configuration#설정을-읽어-오는-곳) |

## 사용 예시

```tsx
import {
  AgentProvider,
  AssistantButton,
  useAgent,
  LogLevel,
} from '@viamoss/moss-sdk';
import type { MossSDKConfig, AgentState } from '@viamoss/moss-sdk';

const config: MossSDKConfig = {
  apiUrl: 'https://moss-api.viamoss.ai',
  applicationId: 'your-app-id',
  userId: 'user-123',
  getJwt: async () => fetchToken(),
  logLevel: LogLevel.INFO,
};

function App() {
  return (
    <AgentProvider config={config}>
      <AssistantButton />
      <ChatStatus />
    </AgentProvider>
  );
}

function ChatStatus() {
  const { messages, isChatOpen }: AgentState = useAgent();

  return (
    <div>
      <p>Chat is {isChatOpen ? 'open' : 'closed'}</p>
      <p>{messages.length} messages</p>
    </div>
  );
}
```
