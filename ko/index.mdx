## Moss에 오신 것을 환영합니다

Moss는 웹 앱에 넣는 AI 어시스턴트입니다. 사용자가 보고 있는 페이지를 읽고, 여러분의 문서를 바탕으로 질문에 답하며, 클릭할 요소를 하나씩 하이라이트해 작업을 안내할 수 있습니다.

### Moss가 하는 일

- **맥락에 맞게 답합니다.** Moss는 사용자가 보고 있는 페이지의 텍스트와 구조를 읽습니다. 민감하다고 표시한 부분은 마스킹하고 읽으므로, 답변이 사용자가 보는 화면에 맞습니다. [페이지 데이터와 개인정보](/ko/sdk/page-data)를 참고하세요.
- **단계별로 안내합니다.** Moss는 실제 페이지에서 단계마다 눌러야 할 버튼이나 필드를 하이라이트합니다.
- **지식 베이스로 답합니다.** 헬프 센터나 문서를 연결하면, Moss가 답변의 근거가 된 문서를 인용합니다.
- **지원팀에 넘깁니다.** Moss가 지원 티켓 초안을 작성해 Zendesk에 접수합니다. 직접 접수하거나 여러분의 백엔드를 통해 접수할 수 있습니다.
- **세션을 재생합니다.** 세션 녹화를 켜면(기본으로 꺼져 있음) 사용자가 한 일을 대시보드에서 다시 볼 수 있습니다.

## 리소스

### 대시보드

[Moss 대시보드](https://dashboard.viamoss.ai)에서 다음을 할 수 있습니다.

- 애플리케이션 만들기와 설정
- 지식 베이스, 프로시저, 추천 콘텐츠 관리
- 세션, 세션 리플레이, 분석 검토

자체 호스팅 설치에는 별도의 대시보드 주소가 있습니다.

### 지원

도움이 필요하신가요? [문제 해결 가이드](/ko/sdk/advanced#문제-해결)를 확인하거나 대시보드를 통해 지원팀에 문의하세요.
