## 개요

**세션** 목록에서 세션을 CSV나 JSON으로 내보낼 수 있습니다. 내보내기 유형은 두 가지입니다.

- **세션 요약**(기본값): 세션당 한 행이며, 세션의 각종 수와 평가가 담깁니다.
- **전체 대화 기록**: 메시지당 한 행이며, 답변마다의 평가와 피드백이 담깁니다.

관리자와 멤버 모두 내보낼 수 있습니다. 내보내는 방법은 다음과 같습니다.

1. **분석 > 세션**을 열고, 검색창과 **필터**로 목록을 좁힙니다([세션](/ko/dashboard/sessions#필터) 참고).
2. **내보내기**를 누릅니다.
3. 필요하면 내보내기 패널에서 **사용자 ID**, **생성일**, **마지막 활동**, **세션 평가**, **메시지 평가**를 지정합니다.
4. **내보내기 유형**을 고릅니다.
5. **CSV로 내보내기** 또는 **JSON으로 내보내기**를 누릅니다.

파일은 `sessions-export-<date>.csv` 또는 `.json` 이름으로 내려받아지며, 날짜는 UTC 기준입니다(예: `sessions-export-2026-11-24.csv`).

<Warning>
  0.17.0에서는 **세션 요약**을 JSON으로 내보내면 **내보내기에 실패했습니다** 오류가 납니다. 세션 요약은 CSV로 내보내고, JSON이 필요하면 **전체 대화 기록**을 쓰세요.
</Warning>

## 내보내는 세션

내보내기에는 다음 조건을 모두 만족하는 세션이 담깁니다.

- **내보내기 패널의 필드**: **사용자 ID**(입력한 텍스트가 들어 있는 ID, 대소문자 구분 없음), **생성일** 시작과 끝, **마지막 활동** 시작과 끝, **세션 평가**(도움됨, 도움 안됨, 보통, 미평가), **메시지 평가**(도움됨, 도움 안됨). 이 필드는 **필터** 패널의 같은 이름 필드와 별개이므로 여기서 지정하세요. **분석** 페이지의 **세션 보기** 링크처럼 **생성일** 필터가 걸린 상태로 목록을 열었다면, 패널의 **생성일**도 처음에 그 기간으로 채워져 있습니다.
- **목록의 검색과 결과 필터**: 그대로 넘어갑니다. 검색창, **주제**, **답변 상태**, **해결 여부**, **도구 실행**, 그리고 **분석** 링크가 추가하는 **아티클**과 **콘텐츠 공백 기간** 칩입니다.

목록의 **녹화** 필터는 넘어가지 않으며, 내보내기 패널에도 이 필드가 없습니다.

목록과 마찬가지로 메시지가 하나 이상 있는 세션만 내보냅니다.

## 제한

| 제한 | 적용 대상 | 동작 |
|---|---|---|
| 세션 5,000개 | 두 유형 모두 | 조건에 맞는 세션 중 가장 최근에 갱신된 5,000개를 읽습니다. 나머지는 아무 안내 없이 빠지므로, **세션 요약**은 5,000행을 넘지 않고 **전체 대화 기록**은 최대 5,000개 세션을 담습니다. |
| 10,000행 | **전체 대화 기록** | 읽은 세션의 메시지가 10,000개를 넘으면 아무것도 내보내지 않고, 대시보드에 "행이 너무 많습니다. 필터를 좁혀주세요."가 표시됩니다. 그 뒤의 오류 메시지는 `Export exceeds 10000 rows (<count> found). Please narrow your filters.`입니다. |

더 많이 내보내려면 **생성일**로 기간을 나누어 기간마다 한 번씩 내보내세요.

## 내보내기 열

### 세션 요약

세션당 한 행이며, 가장 최근에 갱신된 세션부터 나옵니다.

| 열 | 내용 |
|---|---|
| `session_id` | 세션 ID이며, `cs_`로 시작합니다. |
| `user_id` | 앱이 넘긴 사용자 ID입니다. |
| `status` | 서버가 보는 세션 상태, 즉 활성 또는 종료입니다([활성과 종료](/ko/dashboard/sessions#활성과-종료) 참고). 0.17.0에서는 CSV 셀에 `ChatSessionStatus.ACTIVE` 또는 `ChatSessionStatus.CLOSED`로 적힙니다. |
| `created_at` | 세션이 시작된 시각이며, UTC 기준 ISO 8601 형식입니다(예: `2026-11-03T11:58:04.987654+00:00`). |
| `last_activity_at` | 마지막 메시지가 기록된 시각이며, 형식은 같습니다. |
| `message_count` | 목록의 **단계** 수입니다. 사용자의 질문, 안내를 따라 사용자가 페이지에서 한 동작, 어시스턴트의 답변을 세며, 완료된 메시지만 셉니다. |
| `tool_run_count` | 목록의 **도구 실행** 수입니다. |
| `session_rating` | 세션 전체에 대한 평가입니다. `helpful`, `unhelpful`, `neutral`(3점), 또는 빈 값입니다. |
| `session_comment` | 사용자가 그 평가와 함께 남긴 코멘트이며, 없으면 빈 값입니다. |
| `first_user_query` | 사용자가 처음 입력한 질문입니다. |
| `has_recording` | `True` 또는 `False`이며, 세션에 녹화가 있는지 나타냅니다. |
| `session_score` | 1~5점 점수이며, 없으면 빈 값입니다. 0.17.0부터 있습니다. |

```text
session_id,user_id,status,created_at,last_activity_at,message_count,tool_run_count,session_rating,session_comment,first_user_query,has_recording,session_score
```

### 전체 대화 기록

메시지당 한 행입니다. 행은 세션별로 묶이고, 한 세션 안에서는 대화 순서대로 나옵니다. 세션은 날짜순으로 정렬되지 않습니다.

| 열 | 내용 |
|---|---|
| `session_id` | 세션 ID입니다. |
| `user_id` | 앱이 넘긴 사용자 ID입니다. |
| `session_created_at` | 세션이 시작된 시각이며, UTC 기준 ISO 8601 형식입니다. |
| `message_sequence` | 세션 안에서 메시지의 순서입니다. 내보낸 행만 세며, 1부터 시작합니다. |
| `message_type` | `user_query`, `assistant_response`, `system_continuation` 중 하나입니다([메시지 유형 설명](#메시지-유형-설명) 참고). |
| `message_content` | 메시지 텍스트입니다. `assistant_response` 행에서는 문자열로 된 JSON 객체입니다([`assistant_response` 메시지 내용 스키마](#assistant_response-메시지-내용-스키마) 참고). |
| `message_created_at` | 메시지가 기록된 시각이며, UTC 기준 ISO 8601 형식입니다. |
| `message_rating` | 이 답변에 사용자가 누른 평가입니다. `helpful`, `unhelpful`, 또는 빈 값입니다. |
| `ai_rating` | 같은 세션의 이후 답변이 이 답변을 바로잡았으면 `unhelpful`, 그렇지 않으면 빈 값입니다. |
| `session_rating` | 세션 전체에 대한 평가이며, 세션의 모든 행에 반복됩니다. `helpful`, `unhelpful`, `neutral`, 또는 빈 값입니다. |
| `session_comment` | 세션 평가와 함께 남긴 코멘트이며, 세션의 모든 행에 반복됩니다. |
| `message_feedback_reason` | 이 답변에 👎를 누른 뒤 사용자가 고른 이유이며, 없으면 빈 값입니다. 0.17.0부터 있습니다. |
| `message_feedback_comment` | 사용자가 그 이유와 함께 입력한 코멘트이며, 없으면 빈 값입니다. 0.17.0부터 있습니다. |
| `session_score` | 세션의 1~5점 점수이며, 세션의 모든 행에 반복됩니다. 없으면 빈 값입니다. 0.17.0부터 있습니다. |

```text
session_id,user_id,session_created_at,message_sequence,message_type,message_content,message_created_at,message_rating,ai_rating,session_rating,session_comment,message_feedback_reason,message_feedback_comment,session_score
```

`message_feedback_reason`에는 다음 키 중 하나가 담깁니다. 대시보드와 위젯은 문구로 보여 줍니다.

| 키 | 표시되는 문구 |
|---|---|
| `steps_mismatch` | 단계가 화면과 맞지 않았어요 |
| `hard_to_follow` | 가이드를 따라 하기 어려웠어요 |
| `not_solved` | 문제가 해결되지 않았어요 |
| `wrong_answer` | 답변이 틀렸어요 |
| `not_answered` | 질문에 대한 답이 아니었어요 |
| `other` | 기타 |

이유와 점수는 위젯이 물어볼 때만 수집됩니다. [평가와 점수, 이유](/ko/dashboard/sessions#평가와-점수-이유)를 참고하세요.

## 메시지 유형 설명

- `user_query`: 사용자가 입력한 질문입니다.
- `system_continuation`: 사용자가 질문을 입력한 것이 아니라 페이지에서 일어난 일을 계기로 Moss가 시작한 턴입니다. 사용자가 Moss의 안내에 따라 단계를 마쳤거나, 지원 핸드오프의 결과가 돌아온 경우입니다. 내용은 Moss가 어시스턴트를 위해 쓴 텍스트이며, 사용자가 입력한 말이 아닙니다.
- `assistant_response`: 어시스턴트의 답변입니다.

완료된 메시지만 내보냅니다. 답변 없이 실패한 턴이나 다른 턴으로 대체된 턴은 빠지므로, 내보낸 대화 기록이 세션 페이지보다 짧을 수 있습니다.

## `assistant_response` 메시지 내용 스키마

`assistant_response` 행의 `message_content`는 필드 하나짜리 JSON 객체를 문자열로 직렬화한 값입니다.

```json
{"guidance_text": "Click Save in the top-right corner."}
```

`guidance_text`는 사용자가 본 그대로의 답변 텍스트입니다. 다른 필드는 내보내지 않습니다. 답변이 가리킨 요소, 가이드 계획, 단계 갱신은 내보내기에 없습니다. 이 문자열 안에서 ASCII 밖의 문자는 이스케이프됩니다(예: 저장은 `\uc800\uc7a5`). JSON 파서로 읽으면 원래 문자로 돌아옵니다.

## JSON 내보내기의 `assistant_response` 예시

```json
{
  "session_id": "cs_3f1c9a2e-7b4d-4e8a-9c1f-2d6b8e0a5c71",
  "user_id": "user_42",
  "session_created_at": "2026-11-03T11:58:04.987654+00:00",
  "message_sequence": 2,
  "message_type": "assistant_response",
  "message_content": "{\"guidance_text\": \"Click Save in the top-right corner.\"}",
  "message_created_at": "2026-11-03T11:58:07.120000+00:00",
  "message_rating": "unhelpful",
  "ai_rating": "",
  "session_rating": "neutral",
  "session_comment": "",
  "message_feedback_reason": "not_answered",
  "message_feedback_comment": "I asked about bulk export",
  "session_score": 3
}
```

JSON에서 `message_sequence`와 `session_score`는 숫자이며, 비어 있는 `session_score`는 `""`입니다. 나머지 값은 모두 문자열입니다.

## 수식 문자로 시작하는 CSV 셀

스프레드시트가 셀을 수식으로 실행하지 않도록, `=`, `+`, `-`, `@`, 탭, 캐리지 리턴으로 시작하는 CSV 셀 앞에는 `'`가 붙습니다. 예를 들어 `-5 is my balance?` 같은 질문은 `'-5 is my balance?`로 기록됩니다. JSON 내보내기는 바뀌지 않습니다.

## 자주 묻는 질문

**내보낸 결과가 목록과 다른 이유는 무엇인가요?**
내보내기는 세션을 최대 5,000개까지만 읽으므로 목록보다 적을 수 있습니다. 또 목록의 **녹화** 필터를 무시하고, **필터**의 사용자 ID, 날짜, 평가 필드 대신 내보내기 패널의 필드를 쓰므로 목록보다 많을 수도 있습니다. 내보내기 전에 내보내기 패널의 필드를 지정하세요.

**1~5점 점수와 👎 이유는 어디에 있나요?**
`session_score`는 두 유형 모두에, `message_feedback_reason`과 `message_feedback_comment`는 **전체 대화 기록**에 있습니다. 위젯이 수집하지 않으면 비어 있습니다.

**가이드의 단계나 어시스턴트가 실행한 도구도 내보낼 수 있나요?**
내보내기로는 안 됩니다. **전체 대화 기록**에는 답변 텍스트만 있습니다. 도구 실행과 안내된 단계는 세션을 열어 확인하세요. **세션 요약**에는 도구 실행 횟수가 있습니다.

**세션은 얼마나 보관되나요?**
[데이터 및 개인정보](/ko/dashboard/data-privacy)를 참고하세요.
