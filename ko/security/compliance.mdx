## 현재 감사·인증 준비

Moss는 SOC 2 Type II 감사와 ISO/IEC 27001 인증을 준비하고 있습니다. 현재 진행 중이며, 이 페이지는 SOC 2 보고서나 ISO 인증서가 발급됐다는 의미가 아닙니다. 확정된 감사 범위·대상 기간과 진행 상태는 Moss에 문의해 주세요.

정보보안 관리에는 접근 통제, 변경 관리, 사고 대응, 모니터링, 복구와 위험관리가 포함됩니다. 각 통제의 실제 운영과 증빙은 별도로 확인합니다.

## 개인정보 관련 요청

GDPR 등 개인정보 법령이 적용되는 경우, 해당 개인정보처리자가 처리 근거·고지와 정보주체 요청의 처리 방법을 정합니다. 고객 운영형 배포에서는 고객이 자신의 환경을 관리하고, Moss가 별도로 받은 지원용 사본은 적용 계약에 따라 처리합니다.

### 열람과 이동

열람이나 내보내기는 Moss 또는 해당 고객의 관리자에게 요청해 주세요. 제공 가능한 기록과 형식은 서비스·배포에 따라 다릅니다. 개인정보나 다른 사용자의 로그를 제공하기 전에는 요청 권한을 확인해야 합니다.

### 삭제

사용자 삭제 기능은 기본 사용자 기록과 연결된 세션·메시지·플랜·지침 메타데이터를 처리합니다. 지식 자료, 업로드 파일, 벡터, 녹화, 감사 기록, 백업과 외부 서비스의 사본은 별도의 저장·삭제 경로를 가집니다. 사용자 삭제 성공만으로 이 사본까지 모두 삭제됐다고 볼 수는 없습니다.

삭제 요청을 받으면 대상 범위, 관련 저장소와 법정 보존 의무를 확인한 뒤 처리 결과와 남겨야 하는 기록을 안내합니다. 적용 계약과 개인정보처리방침을 따르며, 하나의 API 결과만으로 전체 삭제 완료를 판단하지 않습니다.

### 처리 근거와 계약

동의, 계약 이행, 정당한 이익 등 어떤 근거가 적용되는지는 실제 처리 활동과 법령에 따라 다릅니다. SDK 설정만으로 적법한 근거나 유효한 동의가 성립하는 것은 아닙니다. 적용 DPA, 처리 범위, 수신자와 국외 이전 조건은 Moss에 문의해 주세요.

## EU AI Act

적용 의무와 위험 분류는 의도된 용도, 배포와 각 당사자의 역할에 따라 달라집니다. 모든 배포를 제한된 위험으로 분류하거나 일괄적인 EU AI Act 준수를 주장하지 않습니다.

애플리케이션 운영자는 AI 사용과 한계를 알리고 적절한 사람의 감독을 제공하며, 해당 용도에 필요한 기록을 확인해야 합니다. 제공되는 감사 이벤트가 모든 AI 상호작용의 로깅을 의미하지는 않습니다.

## 도메인 제한

허용 도메인을 설정하면 SDK 초기화를 제한합니다. 목록이 비어 있으면 모든 도메인을 허용합니다. 도메인 제한은 인증을 대신하지 않는 추가 통제입니다.

대시보드 보안 설정에 필요한 운영·개발 환경의 도메인을 등록합니다. 예:

```text
app.example.com
staging.example.com
localhost:3000
```
