## 적용 범위

Moss는 접근통제, 자격증명 보호, 보안 로그와 복구 절차로 취급하는 정보를 보호합니다. 적용되는 기능과 통제는 버전, 설정과 배포 방식에 따라 다릅니다.

Moss가 운영하는 서비스와 고객이 직접 운영하는 설치 환경은 책임이 다릅니다. 고객 운영형에서는 고객이 실행환경과 인프라를 관리하고, Moss는 자체 릴리스·지원과 허용된 접근을 관리합니다. 실제 배포의 책임 범위는 문의해 주세요.

## 보안 통제

| 영역 | 적용 방식 |
| --- | --- |
| 인증 | 해당 서비스 경로의 JWT·API 키 확인, 대시보드의 Clerk 인증 |
| 권한 | 경로와 데이터에 맞는 애플리케이션·조직·세션 확인 |
| 전송 | 공개 서비스 엔드포인트의 HTTPS, 그 외 연결은 해당 배포 설정에 따라 보호 |
| 자격증명 저장 | 지원되는 API 키 검증에는 단방향 해시, 다시 사용해야 하는 연동 토큰·서명 비밀값에는 암호화 |
| 로그 | 선정한 감사 이벤트와 최소한의 운영 로그, 설정에 따른 상세 트래픽 로그 |
| 수집 내용 | 지원 경로의 필터링·마스킹. 캡처에는 개인정보가 남을 수 있음 |

조직 단위 접근통제가 모든 데이터베이스 쿼리의 조직 필터를 뜻하지는 않습니다. 공유 지식자료, 관리자 접근과 고객 운영형 저장소는 각각의 접근 범위를 적용합니다. 실제 경로와 배포를 기준으로 권한을 확인해야 합니다.

## 감사·개인정보 보호

SOC 2 Type II 감사와 ISO 27001 인증을 준비하고 있습니다. 이 페이지는 SOC 2 보고서 발행이나 ISO 27001 인증 취득을 의미하지 않습니다. 현재 범위와 제공 가능한 자료는 문의해 주세요.

삭제·감사·동의 기능은 개인정보 보호 의무 이행에 활용할 수 있습니다. 기능만으로 GDPR이나 EU AI Act의 모든 요구사항을 충족하는 것은 아닙니다. 적용 의무와 역할은 실제 사용 목적, 데이터 흐름과 고객 계약에 따라 확인합니다.
