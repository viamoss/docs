# 변경 이력

Moss SDK(`@viamoss/moss-sdk`)와 Moss 대시보드에서 고객에게 드러나는 주요 변경
사항입니다. v0.13.0부터 SDK 버전은 Moss 플랫폼 버전을 따릅니다.

## 0.16.7 — 2026-09-17

### 추가

- **멀티 아키텍처 온프레미스 이미지.** 모든 온프레미스 이미지 태그
  (`moss-backend`, `moss-worker`, `moss-dashboard`, `moss-dashboard-oidc`)가
  이제 `linux/amd64`와 `linux/arm64` 변형을 담은 매니페스트 목록으로 해석됩니다.
  Cosign 서명과 CycloneDX SBOM 증명은 인덱스 다이제스트와 아키텍처별
  다이제스트를 모두 포함합니다. 미러는 단일 아키텍처 이미지가 아니라 인덱스
  전체를 복사해야 합니다.
- **Moss Studio.** 앱 안에서 가이드를 작성하는 기능으로, 기본적으로 꺼져 있는
  배포 스위치 뒤에서 제공됩니다.

### 변경

- 대시보드 이미지의 Next.js 및 `sharp` 의존성 업데이트(보안 수정).
- 워커 이미지에서 사용하지 않는 NLP 의존성을 제거하고 베이스 이미지를
  갱신했습니다.
- SDK 패키지를 공개 npm 게시에 맞게 준비했습니다(exports 맵, CommonJS 진입점,
  패키징 검사). 접근 권한은 당분간 비공개로 유지됩니다.
- 이번 릴리스에는 데이터베이스 마이그레이션이 없습니다.
- 모든 구성 요소를 차트 0.16.7로 업그레이드하세요. 단계적으로 업그레이드하는
  경우 백엔드를 먼저 업그레이드한 뒤 대시보드를 업그레이드하세요.
- 온프레미스 미러에는 이제 태그마다 단일 이미지 다이제스트 대신 인덱스
  다이제스트가 표시됩니다.

## 0.16.6 — 2026-09-05

### 추가

- **애플리케이션 내보내기 및 가져오기.** 관리자는 Configure > General에서 버전이
  지정된 번들을 내보내고, 애플리케이션 목록의 가져오기 대화상자에서 가져올 수
  있습니다. 번들은 설정과 함께 작성된 애플리케이션 전체를 담습니다. 프로시저,
  API 연결과 액션, 통합 연결, 모니터, 인텐트 태그, 자가 복구 일정이 포함됩니다.
  자격 증명은 절대 포함되지 않으며 대상 환경에서 다시 입력합니다. 직접 등록
  모드의 통합 연결은 생성되지 않고 마무리 항목으로 보고됩니다. 가져오기는 하나의
  트랜잭션으로 실행되며, 드라이런 보고서에는 생성될 항목, 재매핑된 식별자,
  번들과 다르게 기록되는 모든 값, 다시 입력해야 할 항목 체크리스트가 표시됩니다.
  대시보드 내보내기는 기본적으로 전체 번들을 생성하며, 설정만 담은 번들도 계속
  사용할 수 있습니다. 가이드 플로우는 번들에 포함되지 않습니다. 엔드포인트는
  `GET /api/v1/applications/{id}/export`와
  `POST /api/v1/applications/import?dry_run=true`입니다.
- **대시보드에서 관리하는 외관 컨트롤(1차).** 새로운 테마 슬라이스와 푸터 배경
  색조를 대시보드에서 편집할 수 있습니다. SDK는 대시보드에 저장된 값을 리프
  단위로 호스트 prop 위에 적용하므로, 우선순위는 프리셋, 호스트 prop, 대시보드
  값 순입니다. 대시보드 테마 값을 보려면 호스트가 SDK를 0.16.6으로 업그레이드해야
  합니다.
- SDK 채팅 창을 헤더 전체와 창 가장자리에서 드래그할 수 있습니다.
- 대시보드 토스트에 닫기 버튼이 추가되었고, 오류 토스트는 닫을 때까지 유지됩니다.

### 변경

- 설정 슬라이스의 마지막 리프를 지우면 빈 객체를 저장하는 대신 슬라이스 자체가
  제거됩니다.
- SDK 패키지 tarball에 더 이상 소스맵이 포함되지 않으며, 공개 README와 패키지
  메타데이터가 추가되었습니다.
- 분리 배포 환경의 업그레이드 순서: 백엔드, 대시보드, SDK 순입니다.
- 애플리케이션 정리(prune) 스크립트가 애플리케이션 소유 테이블 전체를 다루고,
  저장된 DOM 스냅샷 객체를 제거하며, 설정된 데이터베이스 스키마를 통해 테이블을
  찾습니다. 애플리케이션 간 참조가 감지되거나 테이블 수를 셀 수 없으면 실행을
  거부합니다.
- 이번 릴리스에는 데이터베이스 마이그레이션이 없습니다.

### 알려진 문제

- 링크만 저장된 푸터의 경우 공개 설정 엔드포인트가 `enabled: false`를 반환합니다.
- 설치 환경에 같은 이름의 애플리케이션이 이미 있는 조직으로 가져오기하면
  거부됩니다. 현재 애플리케이션 이름은 설치 환경 단위로 고유합니다.

## 0.16.5 — 2026-09-02

### 보안

- 워커 의존성 보안 업데이트(`nltk`).

### 변경

- 0.16.4 수정 사항을 모두 포함하는 첫 번째 완전한 온프레미스 이미지 세트입니다.
  0.16.4를 건너뛴 온프레미스 배포는 0.16.5로 바로 업그레이드하세요.
- 분리 배포 환경에서는 백엔드를 먼저 업그레이드한 뒤 대시보드를 업그레이드하세요.

## 0.16.4 — 2026-09-02

<Warning>
  0.16.4의 워커 이미지는 취약점 게이트에 걸려 게시되지 않았습니다. 온프레미스
  배포는 0.16.4의 모든 수정 사항을 포함한 0.16.5를 사용하세요.
</Warning>

### 수정

- 프로시저, 커스텀 API 액션, 통합, 모니터, 제안 대시보드 페이지가 OIDC로
  로그인하는 배포에서도 동작합니다.
- 대시보드에서 설정한 프롬프트별 제로 스테이트 아이콘이 SDK에 설정한 그대로
  표시되며, 한 번의 저장으로 켤 수 있습니다.
- 공개 SDK 설정 엔드포인트가 알 수 없는 제로 스테이트 키를 만나도 실패하지 않고
  무시합니다.

### 변경

- 베이스 이미지 갱신.

## 0.16.3 — 2026-08-27

### 수정

- 배포 환경에서 audience(`aud`) 클레임을 요구하지 않는 경우, 해당 클레임이 포함된
  SDK 토큰이 더 이상 거부되지 않습니다.
- 설정된 모델이 지원하지 않는 추론 수준은 요청을 실패시키지 않고 가장 가까운
  지원 수준으로 조정됩니다.
- 대시보드의 외관 또는 보안 폼을 저장해도 SDK 외관 프리셋을 덮어쓰지 않으며, 각
  폼은 자신의 필드만 저장합니다.

## 0.16.2 — 2026-08-23

### 보안

- 베이스 이미지 보안 갱신. 0.16 라인에서 처음으로 게시된 온프레미스 이미지
  세트입니다.

## 0.16.1 — 2026-08-23

<Warning>
  0.16.1의 이미지는 취약점 게이트에 걸려 게시되지 않았습니다. 온프레미스 배포는
  0.16.1의 모든 수정 사항을 포함한 0.16.2 이상을 사용하세요.
</Warning>

### 수정

- 공개 SDK 설정 엔드포인트가 모든 백엔드 서비스 모드에서 제공되므로, SDK
  백엔드만 노출하는 분리 배포 환경에서도 SDK를 부트스트랩할 수 있습니다.
- 대시보드 보안 페이지의 공개 키 입력란이 더 이상 영역을 넘어 표시되지 않습니다.

### 보안

- 대시보드 의존성 보안 업데이트(`nanoid`).

## 0.16.0 — 2026-08-17

### 추가

- **지원 티켓 핸드오프** — 어시스턴트가 지원 요청 내용을 수집하고, 사용자에게 검토
  카드를 보여준 뒤, 확인된 티켓을 애플리케이션에 넘겨 자체 백엔드를 통해 등록하도록
  할 수 있습니다. [지원 티켓 핸드오프](/ko/sdk/support-ticket-handoff)를
  참조하세요. 티켓 등록은 해당 기능이 설정된 애플리케이션에서, 호스트가
  `onSupportTicket` 콜백을 등록한 세션에만 제안됩니다.
- **세션 상세** — 대시보드 세션 페이지가 대화 기록을 더 명확하게 묶어 보여주며,
  여러 표시 관련 문제를 해소했습니다.

### 수정

- 여러 줄 입력(Shift+Enter)이 축약형 가이드 버블에서도 동작합니다.
- 조직 경계를 넘는 대시보드 딥링크가 실패하지 않고 애플리케이션의 소속 조직으로
  복구됩니다.

## 0.15.4 — 2026-08-10

### 보안

- 의존성 보안 업데이트.

## 0.15.3 — 2026-08-10

### 추가

- **지식 기반 진행률** — 문서 소스에 스크랩 단계와 처리 단계가 분리된 구간형
  진행률 표시줄이 표시됩니다.

### 수정

- 가이드를 이어서 진행할 때 세션 대화 기록에 사용자 턴이 중복 기록되지 않습니다.
- 여러 개의 허용 audience 지원을 포함해 온프레미스 OIDC 로그인을 강화했습니다.

## 0.15.0–0.15.2 — 2026-08-06

### 추가

- **세션 대화 기록 개편** — 대시보드가 세션을 자극/응답이 짝지어진 카드, 사용자 역할
  레이블, 날짜 구분선을 갖춘 채팅 스트림으로 렌더링합니다.

### 수정

- 어시스턴트 응답의 줄바꿈이 채팅, 스트리밍, 가이드 안내에서 올바르게 렌더링됩니다.

## 0.14.0 — 2026-08-06

### 추가

- **여러 줄 채팅 입력** — Enter는 전송, Shift+Enter는 줄바꿈입니다.
- 대시보드 세션 대화 기록의 어시스턴트 응답이 마크다운으로 렌더링됩니다.
- Document360 소스의 인용이 공개 포털 URL로 연결됩니다.

## 0.13.0 — 2026-08-05

### 변경

- SDK 버전이 Moss 플랫폼 버전을 따릅니다.
- 세션 재개 카드 개편: 평가 요청을 가운데 정렬하고, 이어서 진행할지 새로 시작할지
  선택하는 부분을 간결하게 정리했습니다.

### 수정

- 새 채팅을 시작한 뒤 이전 응답이 나타나는 문제를 방지했습니다.
- 오래된 대기 중 상호작용으로 재개되는 문제를 방지했습니다.
