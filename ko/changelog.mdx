# 변경 이력

Moss SDK(`@viamoss/moss-sdk`)와 Moss 대시보드에서 고객에게 드러나는 주요 변경
사항입니다. v0.13.0부터 SDK 버전은 Moss 플랫폼 버전을 따릅니다.

## 0.16.5 — 2026-09-02

### 보안

- 워커 의존성 보안 업데이트(`nltk`).

### 변경

- 0.16.4 수정 사항을 모두 포함하는 첫 번째 완전한 온프레미스 이미지 세트입니다.
  0.16.4를 건너뛴 온프레미스 배포는 0.16.5로 바로 업그레이드하세요.
- 분리 배포 환경에서는 백엔드를 먼저 업그레이드한 뒤 대시보드를 업그레이드하세요.

## 0.16.4 — 2026-09-02

<Warning>
  0.16.4의 워커 이미지는 취약점 게이트에 걸려 게시되지 않았습니다. 온프레미스
  배포는 0.16.4의 모든 수정 사항을 포함한 0.16.5를 사용하세요.
</Warning>

### 수정

- 프로시저, 커스텀 API 액션, 통합, 모니터, 제안 대시보드 페이지가 OIDC로
  로그인하는 배포에서도 동작합니다.
- 대시보드에서 설정한 프롬프트별 제로 스테이트 아이콘이 SDK에 설정한 그대로
  표시되며, 한 번의 저장으로 켤 수 있습니다.
- 공개 SDK 설정 엔드포인트가 알 수 없는 제로 스테이트 키를 만나도 실패하지 않고
  무시합니다.

### 변경

- 베이스 이미지 갱신.

## 0.16.3 — 2026-08-27

### 수정

- 배포 환경에서 audience(`aud`) 클레임을 요구하지 않는 경우, 해당 클레임이 포함된
  SDK 토큰이 더 이상 거부되지 않습니다.
- 설정된 모델이 지원하지 않는 추론 수준은 요청을 실패시키지 않고 가장 가까운
  지원 수준으로 조정됩니다.
- 대시보드의 외관 또는 보안 폼을 저장해도 SDK 외관 프리셋을 덮어쓰지 않으며, 각
  폼은 자신의 필드만 저장합니다.

## 0.16.2 — 2026-08-23

### 보안

- 베이스 이미지 보안 갱신. 0.16 라인에서 처음으로 게시된 온프레미스 이미지
  세트입니다.

## 0.16.1 — 2026-08-23

<Warning>
  0.16.1의 이미지는 취약점 게이트에 걸려 게시되지 않았습니다. 온프레미스 배포는
  0.16.1의 모든 수정 사항을 포함한 0.16.2 이상을 사용하세요.
</Warning>

### 수정

- 공개 SDK 설정 엔드포인트가 모든 백엔드 서비스 모드에서 제공되므로, SDK
  백엔드만 노출하는 분리 배포 환경에서도 SDK를 부트스트랩할 수 있습니다.
- 대시보드 보안 페이지의 공개 키 입력란이 더 이상 영역을 넘어 표시되지 않습니다.

### 보안

- 대시보드 의존성 보안 업데이트(`nanoid`).

## 0.16.0 — 2026-08-17

### 추가

- **지원 티켓 핸드오프** — 어시스턴트가 지원 요청 내용을 수집하고, 사용자에게 검토
  카드를 보여준 뒤, 확인된 티켓을 애플리케이션에 넘겨 자체 백엔드를 통해 등록하도록
  할 수 있습니다. [지원 티켓 핸드오프](/ko/sdk/support-ticket-handoff)를
  참조하세요. 티켓 등록은 해당 기능이 설정된 애플리케이션에서, 호스트가
  `onSupportTicket` 콜백을 등록한 세션에만 제안됩니다.
- **세션 상세** — 대시보드 세션 페이지가 대화 기록을 더 명확하게 묶어 보여주며,
  여러 표시 관련 문제를 해소했습니다.

### 수정

- 여러 줄 입력(Shift+Enter)이 축약형 가이드 버블에서도 동작합니다.
- 조직 경계를 넘는 대시보드 딥링크가 실패하지 않고 애플리케이션의 소속 조직으로
  복구됩니다.

## 0.15.4 — 2026-08-10

### 보안

- 의존성 보안 업데이트.

## 0.15.3 — 2026-08-10

### 추가

- **지식 기반 진행률** — 문서 소스에 스크랩 단계와 처리 단계가 분리된 구간형
  진행률 표시줄이 표시됩니다.

### 수정

- 가이드를 이어서 진행할 때 세션 대화 기록에 사용자 턴이 중복 기록되지 않습니다.
- 여러 개의 허용 audience 지원을 포함해 온프레미스 OIDC 로그인을 강화했습니다.

## 0.15.0–0.15.2 — 2026-08-06

### 추가

- **세션 대화 기록 개편** — 대시보드가 세션을 자극/응답이 짝지어진 카드, 사용자 역할
  레이블, 날짜 구분선을 갖춘 채팅 스트림으로 렌더링합니다.

### 수정

- 어시스턴트 응답의 줄바꿈이 채팅, 스트리밍, 가이드 안내에서 올바르게 렌더링됩니다.

## 0.14.0 — 2026-08-06

### 추가

- **여러 줄 채팅 입력** — Enter는 전송, Shift+Enter는 줄바꿈입니다.
- 대시보드 세션 대화 기록의 어시스턴트 응답이 마크다운으로 렌더링됩니다.
- Document360 소스의 인용이 공개 포털 URL로 연결됩니다.

## 0.13.0 — 2026-08-05

### 변경

- SDK 버전이 Moss 플랫폼 버전을 따릅니다.
- 세션 재개 카드 개편: 평가 요청을 가운데 정렬하고, 이어서 진행할지 새로 시작할지
  선택하는 부분을 간결하게 정리했습니다.

### 수정

- 새 채팅을 시작한 뒤 이전 응답이 나타나는 문제를 방지했습니다.
- 오래된 대기 중 상호작용으로 재개되는 문제를 방지했습니다.
