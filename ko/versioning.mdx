# 버전 및 호환성

## 하나의 버전 번호

`@viamoss/moss-sdk`는 Moss 플랫폼과 같은 주기로 릴리스됩니다. SDK 릴리스는 함께
배포되는 백엔드 및 대시보드 릴리스와 동일한 버전 번호를 가집니다. SDK 0.16.0은
Moss 플랫폼 0.16.0용 클라이언트입니다. 이 방식은 0.13.0부터 적용되고 있습니다.

같은 번호의 조합이 Moss가 함께 빌드하고 테스트하는 조합입니다. 이전 버전 SDK를
현재 플랫폼에 대해 실행해도 대체로 동작합니다. 새 버전이 나왔다고 해서 백엔드가
기존 클라이언트를 곧바로 끊지는 않습니다. 다만 이후 릴리스에서 추가된 기능은 이전
SDK에 존재하지 않으며, 수정 사항도 해당 수정이 포함된 버전에만 반영됩니다.

## 이 문서가 다루는 범위

문서는 **최신 릴리스**를 기준으로 작성됩니다. 최근에 추가된 기능에는 "SDK
0.16.0부터 사용할 수 있습니다"와 같은 안내가 함께 표시됩니다. 이전 버전에 고정해
사용 중이라면 그런 안내가 없는 내용은 사용 가능한 것으로 보고, 사용 중인 버전 이후에
추가된 내용은 [변경 이력](/ko/changelog)에서 확인하세요.

## 최신 버전 유지

패키지 매니저로 업그레이드하세요:

```bash
npm install @viamoss/moss-sdk@latest
```

특정 버전에 무기한 고정하기보다는 최근 버전 범위 안에서 사용하세요. 플랫폼은 계속
발전하며, 오래 방치된 클라이언트에는 반영되지 않은 수정 사항이 쌓입니다. 각
릴리스에서 고객에게 드러나는 주요 변경 사항은 [변경 이력](/ko/changelog)에
정리되어 있습니다.

<Info>
    설정 변경이나 호환되지 않는 API 변경 등 고객 측 조치가 필요한 릴리스는 직접
    안내드립니다. 특정 버전이 여러분의 통합에 영향을 주는지 확인이 필요하면
    대시보드를 통해 지원팀에 문의하세요.
</Info>
